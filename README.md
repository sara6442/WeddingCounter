# عدّاد المعازيم

موقع من ملف واحد (`index.html`) بلا تثبيت ولا خادم. يحفظ بياناته في متصفح المستخدم (localStorage).

## النشر على GitHub Pages
1. أنشئ مستودعًا جديدًا على GitHub.
2. ارفع الملف `index.html` (و`README.md` إن شئت) إلى الفرع الرئيسي.
3. من Settings ← Pages اختر Deploy from a branch ثم `main` و `/ (root)`.
4. افتح الرابط الذي يظهر (يشبه `https://اسمك.github.io/اسم-المستودع/`).
